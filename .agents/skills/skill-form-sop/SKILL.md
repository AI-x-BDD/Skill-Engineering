# SOP

## Phase 1 -- 讀取目標

1. READ 讀取目標 skill 的 SKILL.md，確認要新增、修改或重寫的 SOP 範圍。

## Phase 2 -- 撰寫並通過檢查

1. THINK 整理最小可用的 phase 與 step；需要判斷 Phase/Step 格式、動詞選用時，才讀取 `rules/SOP-格式規範.md`；需要判斷步驟取捨、RuleFile 載入位置時，才讀取 `rules/SOP-載入與精簡-格式規範.md`；並依實際讀取到的規則收斂。
2. WRITE 撰寫或修改目標 skill 的 SOP section。
3. READ 回頭檢查結果是否符合本次實際載入的規則；若不符合，立即修正。
