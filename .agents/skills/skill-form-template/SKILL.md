# SOP

## Phase 1 -- 讀取目標

1. READ 讀取 `rules/樣板組成-格式規範.md`，將其視為唯一樣板組成規範來源。
2. READ 依樣板組成規範，讀取目標骨架檔與對應範例檔的既有內容（尚未建立者視為新增），確認要新增、修改或重寫的樣板範圍。

## Phase 2 -- 完成骨架與範例

1. READ 讀取 `rules/骨架-格式規範.md`，將其視為唯一骨架規範來源。
2. THINK 依樣板組成規範與骨架規範，整理最小可用的樣板結構，決定骨架與範例的內容分工、填位符號的格式與名稱。
3. WRITE 依骨架規範與思考結果，撰寫骨架檔。
4. READ 讀取 `rules/範例-格式規範.md`，將其視為唯一範例規範來源。
5. WRITE 依範例規範與思考結果，將骨架填寫完成，撰寫範例檔。
6. READ 依樣板組成規範、骨架規範與範例規範，回頭核對骨架與範例是否成對、結構一致、命名正確；若不符合，立即修正。
